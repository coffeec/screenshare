## Modification & Deployment Guardrail
Before modifying any source code files or running deployment commands/scripts (e.g., `systemctl`, `deploy.ps1`), you MUST:
1. Clearly explain the proposed changes and the rationale behind them.
2. Explicitly ask the user for permission to proceed.
3. Wait for the user's explicit confirmation (e.g., "可以", "ok", "go ahead") before making any actual file edits or executing deployment commands.
